# .github

Organisation-wide defaults for [CAPRO](https://github.com/capro-uio).

| Path | Purpose |
|---|---|
| `profile/README.md` | The landing page shown at [github.com/capro-uio](https://github.com/capro-uio). |
| `CODE_OF_CONDUCT.md` | Applies to every CAPRO repository that does not define its own. |
| `CONTRIBUTING.md` | Default contributing guide. |
| `SECURITY.md` | How to report a vulnerability. |
| `.github/ISSUE_TEMPLATE/` | Default issue forms. |
| `.github/PULL_REQUEST_TEMPLATE.md` | Default pull request template. |

A repository that ships its own copy of any of these overrides the default here.
