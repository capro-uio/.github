# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately through GitHub's
[security advisory form](https://github.com/capro-uio/.github/security/advisories/new)
on the affected repository, or by email to the CAPRO team at the University of
Oslo via [our website](https://www.capro.dev/#contact).

Include what you found, which repository and version it affects, and how to
reproduce it. We aim to acknowledge reports within a week and will keep you
updated while we work on a fix.

## Supported versions

Our packages are developed in the open and fixes land on `main`. Unless a
repository says otherwise, only the latest release is supported.
